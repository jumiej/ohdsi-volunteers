# Software review

| Tool | What it does | Repo |
|------|-------------|-------|
| Ares | An open-source framework developed by OHDSI (Observational Health Data Sciences and Informatics) designed for use in the study of patient-level observational data that has been converted into the Observational Medical Outcomes Partnership (OMOP) Common Data Model (CDM) to improve transparency and exploration in observational health data research. It achieves this by aggregating and visualizing data quality and characterization metrics (generated by tools like Achilles and the DataQualityDashboard) rather than querying the raw patient-level database directly in real time | https://github.com/ohdsi/ares
| Atlas| ATLAS is a free, open-source, web-based tool developed by the OHDSI community that facilitates the design and execution of scientific analyses on standardized, patient-level, observational data. Deployed as a client-side interface alongside the Java-based OHDSI WebAPI, it enables cohort building, population characterization, and machine-learning predictions without requiring users to write direct SQL queries. Because executing these real-time analyses requires ongoing access to the underlying patient-level data in the OMOP Common Data Model (CDM), it is typically deployed securely behind an organization’s network firewall.| https://github.com/ohdsi/atlas




ACHILLES is a software tool that runs database-wide characterization analyses to aggregate summary statistics and provide an overall baseline visual understanding of a CDM instance.

Data Quality Dashboard (DQD): Conducts systematic validation checks across every table and field to quantify records that do not conform to specific data model rules and specifications.
